    ⚔️ Match

    Chaque joueur choisit 3 cartes différentes parmi ses cartes obtenues (une même carte peut être choisie par les deux). Les équipes sont ensuite dévoilées sur un terrain de football. Pas encore de combat !

    Comment voulez-vous jouer ?

    📱 Sur le même appareil

    Le joueur 1 choisit ses cartes, puis passe l’appareil au joueur 2.

    📡 Sur deux appareils

    Il faut une connexion internet sur les deux appareils. Aucun compte à créer.

    Tu es…

    1. Donne ce code à l’autre joueur
    2. Il clique sur « Je rejoins une partie » et le tape
    3. La partie démarre toute seule !
    ····

    Pas d’internet ? Connexion manuelle

    Les deux appareils doivent être sur le même Wi‑Fi. Au lieu d’un code court, vous vous échangez deux longs codes (message, mail…).
